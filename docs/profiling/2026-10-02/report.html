Interpretation limits

Nested inclusive times must not be summed. Exclusive spans subtract only other explicitly instrumented spans; they are not pure kernel time. Yappi uses per-thread CPU clocks and exports thread totals plus combined Python-thread function tables. Task process CPU includes all application threads; waited-for child CPU is separate. Logical OBJ bytes count codec traffic, not physical storage transfers. Memray starts after module imports, tracks allocations in the application process including native libraries, and does not track Blender after exec. Its aggregated format records live allocations at peak, not total allocation churn; native symbols may be incomplete on macOS.
